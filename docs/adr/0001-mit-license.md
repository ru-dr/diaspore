# 0001. MIT License

## Status

Accepted, 2026-09-26

## Context

Diaspore is going to be open source, but without a license, nobody can legally use, copy, or change the code by default. The two options I considered were MIT and Apache-2.0.

## Decision

I chose MIT because it's widely popular, and patents aren't a real concern for me since this is both a hobby and a course project.

## Consequences

The good side of MIT is that anyone can use this code however they like, as long as they keep the copyright notice. The bad side is that nobody has to contribute their changes back to this repo, and there is no explicit patent protection from contributors.
